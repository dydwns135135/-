# 음식 쇼츠 자동 편집기

원본 영상에서 뜨기/먹기/씹는 장면(움직임 + 소리가 큰 구간)을 골라 약 1분짜리 9:16 쇼츠를 만든다. 자막 없음.
필요한 것: Python 3, ffmpeg (그 외 패키지 없음)

## 가장 쉬운 방법
- **윈도우**: 영상 파일들을 `edit.bat` 위로 끌어다 놓기 (또는 `raw` 폴더에 넣고 `edit.bat` 더블클릭)
- **맥**: `edit.command` 더블클릭 (영상은 `raw` 폴더에)
- 결과는 `out_날짜시간` 폴더에 생기고 자동으로 열린다. 처음 한 번만 파이썬과 ffmpeg 설치가 필요하다.

## 명령어로 쓰기
```
python autoedit.py raw/ -o out                 # raw 폴더의 영상 전부 사용
python autoedit.py a.mp4 b.mp4 --dry-run       # 렌더 없이 고른 구간만 확인
```

| 옵션 | 설명 |
|---|---|
| `--target 60` | 목표 길이(초) |
| `--seg 3` | 컷 하나의 길이(초). 짧을수록 빠른 템포 |
| `--fit crop` / `blur` | 가로 영상을 가운데 크롭 / 흐린 배경 위에 전체 표시 |
| `--focus 0.5` | crop 시 가로 위치(0 왼쪽 ~ 1 오른쪽) |
| `--min-score 0.15` | 밋밋한 구간 제외 기준 |

## 캡컷에서 이어서 편집
- `out/final.mp4` : 완성본
- `out/clips/` : 컷별 파일(1080x1920, 30fps). 캡컷에 전부 불러오면 번호 순서대로 다시 배치/삭제/순서 변경 가능
- `out/edit_list.csv` : 각 컷이 원본 몇 초 구간인지 기록
