# 한국 주식 종목 분석기

시황 → 테마(돈이 몰리는 곳) → 대장주 순으로 좁혀서, **이미 오른 종목이 아니라 오르기 전 단계 후보**를 객관적 수치로 뽑는다.

```
python -m stock --demo                 # 합성 데이터로 시연
python -m stock --pykrx --out result   # 실데이터 (pip install pykrx)
python -m stock --csv data/            # <종목코드>.csv + KOSPI.csv
python -m stock --pykrx --dart         # + DART 최근 3개월 공시 확인 (DART_API_KEY 필요, opendart.fss.or.kr 무료 발급)
```

## 판단 기준
- **시황**: KOSPI가 20일선·60일선 위인지, 20일선이 오르는지 → 강세/중립/약세/하락
- **종목 점수(100)**: 추세 25(종가>20일선, 20일선>60일선, 20일선 상승) + 60일 고점 근접/돌파 25 + 최근 3일 거래량 증가 20 + 10일 변동폭 수축 10 + 수급 20(외국인·기관 5일 순매수/거래대금, 동반 매수 가산)
- **테마 점수**: 상위 3종목 평균 60% + 20일선 위 종목 비율 25% + 거래대금 증가 15%. 테마 내 최고점이 대장주
- **단계**: `선점 후보`(점수≥60, 20일 +20% 미만) / `상승 진행` / `과열(추격금지)`(5일 +25% 또는 20일선 +25% 이격) / `관망`

## 관찰 우선순위 (종목 정밀 분석)
선점 후보마다 `높음 / 보통 / 낮음` 과 사유를 출력한다. **매수·매도 지시가 아니라 어디부터 들여다볼지의 순서**이며, 과거 시험에서 이 순서가 이후 수익률과 연결된다는 근거는 확인되지 않았다.
- 과열 또는 악재성 공시(유상증자·전환사채·감자·횡령 등) → 낮음
- 점수 75+ · 20일 +12% 미만 · 외국인·기관 동반 순매수 · 호재성 공시(공급계약·수주·특허 등) → 높음
- 호재 공시가 없거나 공시 미확인이면 보통까지만, 시황이 약세/하락이면 한 단계 더 낮춤
- 수급은 외국인·기관·개인 5일 순매수/거래대금으로 표시 (개인만 사고 기관·외국인이 파는 종목은 점수가 낮다)

종목 테마 매핑은 `stock/themes.py` 에서 직접 수정. 임계값은 `stock/analyze.py` 상단 상수.
참고용이며 투자 권유가 아니다. 백테스트로 검증되지 않았으니 소액·손절 원칙과 함께 사용할 것.

## 성과 확인 (`--backtest`, 매주 토요일 자동)
과거 3년치 일봉에서 각 날짜마다 그날까지의 데이터만으로 분석을 다시 돌려 신호 뒤 5·10거래일 수익률을 잰다(수급·공시 제외, 종가 진입 가정).
- 단계별·흐름별 평균 수익률을 기준선(모든 날 평균)과 비교
- **날마다 순위 시험**: 매일 점수(또는 흐름) 상위 3종목이 그날 전체 평균보다 나았는지, 겹치지 않는 표본으로 t값 계산
- 2026-10 첫 시험에서는 한국·미국 모두 선점 후보·상승 우세가 기준선과 구별되지 않았고, 과열·하락 우세 종목이 이후 더 낮다는 근거도 없었다. 따라서 이 리포트는 매수 신호가 아니라 **"돈이 몰리는 곳을 정리한 요약"** 으로만 쓸 것.

## 수급 스냅샷과 수급 버전 시험
수급(외국인·기관·개인)은 과거 이력을 구할 수 없어 위 성과 확인에서 빠진다. 그래서 매일 한국시간 19:30(`stock-snapshot` 워크플로, 텔레그램 없음)에 분석 결과를 `stock-data` 브랜치의 `kr/<날짜>.csv` 로 쌓는다(코드 브랜치와 분리). 16:30 리포트 시점에는 네이버에 당일 외국인·기관 수급이 아직 올라오지 않아 하루 늦은 값이 되기 때문이다. 수급이 그날 것까지 확정되지 않은 스냅샷은 시험에서 제외하고, 확정 비율이 80% 미만이면 텔레그램으로 알린다.
- 스냅샷에는 점수·단계·흐름·수급 비율·외국인/기관/개인 5일 순매수액·마지막 수급 확인일이 들어 있다.
- 매주 토요일 성과 확인이 `--evaluate data` 로 쌓인 스냅샷에 이후 5·10일 수익률을 붙여, 매일 수급 상위 3종목이 그날 평균보다 나았는지 시험한다.
- 5일 기준은 약 60거래일, 10일 기준은 약 110거래일(5개월 남짓)이 쌓여야 판단할 수 있다. 그 전에는 "표본 부족"으로 나온다.

## 시장 훑기 (`--scan`, 한국)
미리 정한 종목 목록 밖에서도 후보를 찾기 위해, 네이버 모바일 JSON(`m.stock.naver.com/api`)의 **테마 목록**에서 오늘 상승 종목 비율이 높고 등락률이 큰 테마 30개를 고르고, 구성 종목(테마당 최대 10개, ETF 제외)을 모아 같은 분석을 돌린다. PC 페이지는 스크립트로 그려지는 새 사이트로 바뀌어 읽을 수 없다.
```
python -m stock --scan --telegram --out result     # Actions: stock-scan
```
- **평일 한국시간 19:40 자동 실행**(수급 확정 뒤, `STOCK_ENABLED=true`일 때). 16:30 기존 종목 리포트와 별개다.
- 같은 종목이 여러 테마에 있으면 점수가 높은 한 줄만 표시, 테마 순위는 상위 10개만 표시
- 구성 종목 주소가 바뀌면 거래대금·상승률 상위 종목으로 대신 훑고, `[훑기]` 줄에 시도한 주소와 상태가 남는다.
- 한계: 오늘 이미 오른 테마를 고르는 방식이라 늦을 수 있고(과열 종목이 많이 나온다), 네이버 API 구조에 의존한다. "대장"은 점수가 가장 높은 종목이지 시가총액이 큰 종목이 아니다.

### 훑기 결과 쌓기와 시험
과거 테마 구성은 구할 수 없어, 매일의 훑기 결과(종목별 점수·단계·수급·소속 테마와 테마 순위)를 `stock-data` 브랜치의 `scan/<날짜>.csv`(테마 순위는 `scan/themes/<날짜>.csv`)에 쌓는다.
- 매주 토요일 성과 확인이 쌓인 훑기 스냅샷에 이후 5·10일 수익률을 붙여 **훑기 점수 상위 3종목·상위 3테마·단계별 종목이 그날 훑은 전체 평균보다 나았는지** 시험한다(겹치지 않는 표본·t값).
- 5일 기준은 약 60거래일, 10일 기준은 약 110거래일이 쌓여야 판단할 수 있다. 그 전에는 "표본 부족"으로 나온다.
- 수급이 그날 것까지 확정되지 않은 날은 시험에서 제외하고, 확정 비율이 80% 미만이면 텔레그램으로 알린다.
