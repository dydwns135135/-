# 실거래 전 점검표 (BTC 앙상블 모멘텀, Bitget)

> 이 문서는 **실거래를 켜기 위한 안내가 아니라 점검표**입니다. 실거래용 워크플로는 일부러 만들지 않았습니다.
> 백테스트는 수익을 보장하지 않습니다. 잃어도 생활에 지장이 없는 금액만 쓰세요.

## 0. 먼저 정정: "격리 마진" 에 대해
이전에 "실거래 전에 격리 마진 설정 문제를 해결해야 한다"고 안내했는데 **과장이었습니다.**
- 이 봇은 레버리지 1배 기준으로 **포지션 금액 = 잔고 × alloc(기본 50%) 이하**만 사고, 롱만 합니다. 이 경우 손실의 상한은 포지션 금액(= 가격이 0이 되는 경우)이라 거래소의 마진 모드(교차/격리)보다 **포지션 크기**가 안전을 좌우합니다.
- 오히려 **격리 + 거래소 레버리지 2배 이상**이면 그 포지션은 가격이 반대로 약 50% 움직일 때 청산될 수 있어 더 위험합니다. 데모 포지션이 `Cross 2x` 로 보인 것도 봇의 레버리지 설정 요청이 거부되어 계정 기본값이 남은 결과입니다(로그의 setup_errors).
- 실거래에서는 **계정의 레버리지 설정을 1배로** 두고, 첫 주문 뒤 Bitget 앱에서 포지션의 레버리지·마진 모드·청산가가 기대와 같은지 직접 확인하세요. (통합 계정과 일반 계정의 설정 방식이 달라 확인이 필요합니다.)

## 1. 데모에서 먼저 확인할 것 (최소 4주)
- [ ] 예정된 실행이 빠짐없이 돌았다 (GitHub 스케줄은 **수십 분 늦거나 가끔 건너뛸 수 있음**: 첫 자동 실행이 27분 늦음).
- [ ] 텔레그램 알림이 매일 왔다. 오류(❌) 알림이 오면 원인을 파악했다.
- [ ] **부분 청산·전량 청산·재진입을 데모에서 한 번 이상 실제로 겪었다** (지금까지는 8개 기간 모두 양(+)이라 부분 청산이 실행된 적이 없음).
- [ ] 데모 손익이 BTC 가격 흐름과 앙상블 규칙에 맞게 움직였다(메시지의 목표 비중과 실제 보유량 일치).
- [ ] Bitget 앱 포지션과 봇 메시지의 수량이 맞는다.

## 2. 실거래 키·계정
- [ ] **실거래용 API 키를 따로 만든다.** 권한은 거래+읽기만, **출금 권한은 끈다.** 2단계 인증과 출금 주소 화이트리스트를 켠다.
- [ ] 키는 GitHub **Secrets에만** 넣는다(채팅·문서에 쓰지 않는다). 데모 키와 이름을 구분한다.
- [ ] **IP 제한 문제**: GitHub 호스팅 서버의 IP는 고정이 아니라 Bitget 키에 IP 제한을 걸기 어렵다. IP 제한이 없으면 키 유출 시 위험이 커지므로 → 계정에 넣는 금액을 작게 유지하거나, IP가 고정된 서버에서 돌리는 방법을 검토한다.
- [ ] 전용 서브계정/전용 잔고에 **봇이 쓸 금액만** 둔다.

## 3. 금액과 안전장치 (이번 PR로 코드에 추가됨)
- [ ] `MOMENTUM_MAX_NOTIONAL` (포지션 금액 상한, USDT): 잔고가 커져도 이 금액을 넘기지 않는다. **처음에는 잃어도 되는 금액의 일부만.**
- [ ] `MOMENTUM_MIN_EQUITY` (최소 잔고, USDT): 잔고가 이 아래로 내려가면 **전량 청산하고 신규 진입을 중단**한다(자동 재개 없음). 손실 한도를 미리 정해 두는 용도.
- [ ] 이 값들은 먼저 **데모에서 일부러 높은 값으로 설정해 차단 장치가 작동하는지** 확인한다.
- [ ] `MOMENTUM_ALLOC` 은 1 이하로 유지한다(레버리지 사용 금지).

## 4. 실거래 워크플로 (아직 없음, 켜기 전에 필요)
- [ ] 데모와 **분리된** 별도 워크플로로 만들고, 수동 승인(예: 실행 때 확인 입력) 후에만 동작하게 한다.
- [ ] 첫 실행은 **최소 금액**으로, 사람이 지켜보는 상태에서 한다.
- [ ] 문제가 생기면 즉시 멈추는 방법(변수 `MOMENTUM_ENABLED` 삭제)을 알고 있다.

## 5. 위험 인식
- 과거 BTC 앙상블의 최대 낙폭은 **-65%** (최근 4~5년은 -27% 안팎). 계좌가 절반 이하로 줄어도 규칙대로 유지할 수 있는 금액이어야 한다.
- 최근 4~5년 기준 연 14~22% 정도가 상한 참고치이며 **손실 해가 있을 수 있다.**
- 선물에는 펀딩비·수수료·슬리피지가 든다(백테스트에 반영했지만 실제와 다를 수 있음).
- 거래소 점검·장애·API 오류로 주문이 안 나가거나 늦을 수 있다.

## 6. 법·세금 (확인 필요)
- 해외 거래소 이용, 가상자산 선물 거래, 세금 신고 관련 규정은 **본인 거주 국가의 규정**을 직접 확인하세요. 이 저장소의 어떤 내용도 법률·세무 조언이 아닙니다.

## 7. 중단 기준을 미리 정하기
- [ ] "잔고가 얼마 아래로 내려가면 멈춘다"를 숫자로 정했다(→ `MOMENTUM_MIN_EQUITY`).
- [ ] "몇 주/몇 달 데모·소액 결과가 기대와 다르면 접는다"를 정했다.
